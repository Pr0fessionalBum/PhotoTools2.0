Build and develop

Requirements

  • Windows 10 version 1809 or newer; Windows 11 recommended
  • .NET 10 SDK
  • ImageMagick 7 with magick on PATH
  • Visual Studio with .NET desktop and WinUI components, or the .NET CLI
  • PowerShell 5.1 or newer

Restore and build

dotnet restore
dotnet build -p:Platform=x64 -r win-x64

For a verification build without creating an app host:

dotnet build -p:Platform=x64 -r win-x64 --no-restore -p:UseAppHost=false

Run through Launch Photo Tools 2.bat, Visual Studio, or the generated x64 executable.

Development conventions

  • Keep long-running work off the UI thread and report progress.
  • Use shared folder, format, selection, dialog, Explorer, and process helpers.
  • Limit concurrent image decoding to avoid exhausting memory.
  • Reuse thumbnails, PDF previews, and file indexes; invalidate them when source state changes.
  • Preview destructive operations and test with copied data.
  • Build x64 before testing native OpenCV behavior.
  • Add a repeatable fixture or benchmark for performance-sensitive detector changes.

GitHub Pages

The documentation is plain HTML under docs/. Open docs/index.html for local preview. Pushes to main that modify documentation trigger the Pages workflow. In repository settings, set Pages source to GitHub Actions.
