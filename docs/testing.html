Repeatable evaluation

Performance and accuracy testing

Use the same deterministic fixtures and settings before and after a change so differences are attributable to the code.

Batch launchers

Generate fixtures

Scripts\Generate-ScannerLineTestFixtures.bat

Creates deterministic Small, Large, and Mixed sets with tracked clean, continuous, and interrupted cases.

Performance suite

Scripts\Run-PhotoToolsPerformanceSuite.bat

Measures discovery, enumeration, and thumbnail decoding.

Accuracy suite

Scripts\Run-ScannerLineAccuracyTest.bat

Prints color-coded accuracy, precision, recall, and interrupted-line accuracy.

Generated fixture suite

.\Scripts\Invoke-PhotoToolsPerformanceSuite.ps1 `
  -Case All -Iterations 7 `
  -ScannerLineImagesPerCase 40 `
  -InterruptedScannerLineImagesPerCase 12 `
  -Regenerate

Fixtures use a fixed seed but distinct photo-like backgrounds. Lines vary by orientation, position, width, signed contrast, and interruption ranges. Ground truth is stored beside each fixture.

Scanner accuracy

.\Scripts\Measure-ScannerLineAccuracy.ps1 `
  .\performance-fixtures\small `
  -Sensitivity 0.55 -TargetAccuracy 90

Build the standalone runner with:

dotnet build .\Tools\ScannerLineAccuracyRunner\ScannerLineAccuracyRunner.csproj --configuration Release

Reports include per-image failure stages and pre-filter candidate measurements for traceable tuning.

Performance baseline

.\Scripts\Measure-PhotoToolsPerformance.ps1 'D:\Photos\Large Album' -Iterations 7

Compare a later run:

.\Scripts\Measure-PhotoToolsPerformance.ps1 `
  'D:\Photos\Large Album' -Iterations 7 `
  -CompareWith '.\performance-results\performance-baseline.json'

Outputs

FolderContents
performance-results/Detailed JSON.
test results/Readable timestamped summaries.
performance-fixtures/Generated images and ground truth.

These folders are ignored by Git.

Fair comparisons: use the same fixture seed, sensitivity, iterations, build configuration, and machine load.
