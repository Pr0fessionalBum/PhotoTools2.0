Windows photo workflow

Organize, inspect, and process scanned photo collections.

Photo Tools 2.0 is a local-first WinUI application for album browsing, batch image processing, PDF conversion, naming, statistics, and scanner-line analysis.

Get startedBuild from source

What it can do

Browse

Album Hub

Search, sort, select, preview, rotate, and route album files to other tools.

Process

Image workflows

Batch crop, convert PNG files, compare replacements, and preserve originals through staged outputs.

Convert

PDF to JPG

Add multiple PDFs, cache page previews, rotate or exclude pages, edit output names, then export selected pages or everything.

Organize

Naming tools

Preview front/back naming and repair sequence numbering before applying file changes.

Analyze

Photo statistics

Calculate album details and scanning sessions, then export the result to CSV.

Inspect

Scanner-line detection

Find horizontal, vertical, faint, and interrupted scanner streaks without modifying source photos.

Designed for large local collections

Responsive

Background enumeration, bounded concurrency, thumbnail caching, PDF preview preloading, and indexed replacement matching keep the interface responsive.

Reviewable

Previews, progress reporting, cancellation, comparisons, and editable output names make batch operations understandable before they run.

Local-first

Your photos remain on your computer. Analysis does not upload images or alter originals.

Before bulk changes: work from a backup of irreplaceable scans and test file-changing tools on a copied folder first.
