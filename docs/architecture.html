Core services

FolderBrowserService

Shared folder picking, navigation, enumeration, Explorer actions, and format filtering.

ThumbnailCacheService

Reusable thumbnail decoding and caching for responsive navigation.

AlbumFileIndexService

One reusable index per album, invalidated after operations.

ExternalProcessRunner

Bounded concurrency, cancellation, error capture, and availability checks.

PdfPreviewCacheService

Memory and disk page-preview caching with adjacent-page preloading.

ScannerLineDetector

Reduced decoding, candidate screening, structural validation, position buckets, and result caching.

Scanner-line pipeline

  1. Decode large JPEGs at a reduced analysis resolution with bounded concurrency.
  2. Run a fast profile pass for likely horizontal and vertical positions.
  3. Measure 32 bands for coverage, continuity, width, intensity, contrast, end reach, drift, and gaps.
  4. Penalize borders, broad edges, and symmetric frame pairs.
  5. Use position buckets for efficient batch recurrence.
  6. Apply continuous, recurring-partial, and interrupted-line acceptance paths.
  7. Cache by path, size, modification time, sensitivity, and algorithm version.

Safety boundaries

Folder analysis and scanner detection are read-only. Conversions target separate output folders. Rename and replacement operations provide a preview and explicit apply step. New file-changing workflows should separate discovery from mutation, support cancellation, and invalidate relevant indexes and caches.
