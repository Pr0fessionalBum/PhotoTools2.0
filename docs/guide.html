User guide

Using Photo Tools

Getting started

  1. Install Windows 10 1809 or newer, the .NET 10 SDK, and ImageMagick 7.
  2. Clone or download the repository and run Launch Photo Tools 2.bat.
  3. Choose a workspace from the left sidebar.
  4. Paste, choose, or drag in a folder, then review your selection and options.
  5. Start the operation and monitor progress. Cancel when available.
ImageMagick: crop and conversion workflows need the magick command on PATH. Check with magick -version.

Album Hub

Choose a collection folder to discover album folders. Select an album to browse its files, search by name, sort by name/date/type/size, and use All, Invert, or Clear for selection. Context menus open a photo or reveal it in Explorer. “Send to tool” carries the selected album into another workspace.

The image viewer supports previous/next navigation and queued rotations. Rotations can be reviewed across several images and applied together at the folder level.

Crop / Trim

Select images, configure the crop operation, preview the intended work, and start the batch. Output defaults to a separate cropped folder. Processing runs through the shared ImageMagick runner with progress, cancellation, concurrency limits, and consistent errors.

PNG to JPG

Select PNG files and choose quality and output options. By default, converted copies are written to a JPG subfolder rather than replacing source images.

Replacements

The replacement workspace indexes an album once, matches staged cropped/JPG files to originals by filename, and separates matched and unmatched files. Compare originals and replacements side by side before processing. Empty staging folders never trigger source cleanup.

PDF to JPG

  1. Use Add PDFs to select one or several documents. Add more rows whenever needed.
  2. Edit each document’s output-name prefix.
  3. Select a document and browse its page thumbnails. Neighboring pages preload, and previews are cached in memory and on disk.
  4. Rotate pages and include or exclude them from export. Rotation remains non-destructive until conversion.
  5. Choose quality, DPI, and output location, then export selected pages or all included pages.

Generated JPG files are copies; source PDFs are not modified.

Front / Back and Fix Numbering

Front / Back creates ordered names with A/B suffix handling. Fix Numbering repairs sequence names. Both tools generate a rename preview first—review conflicts and destinations before applying.

Photo Stats

Choose an album and idle-gap duration, then generate statistics from file timestamps. The tool groups scanning activity into sessions and reports counts, active time, average size, date range, and file types. Export the session report to CSV. Copied or converted files may have changed timestamps, so verify dates before billing.

Scanner Lines

Choose a scan folder, decide whether to include subfolders, set sensitivity, and select Analyze photos. Higher sensitivity finds fainter lines but can flag genuine image details. The detector analyzes horizontal and vertical candidates, including short interruptions, while using repeated positions across a batch as supporting evidence.

Double-click a result to compare original and highlighted views. Drag to pan, use the wheel to zoom, and use Left/Right arrows for adjacent results. This workflow is read-only.

Troubleshooting

ProblemCheck
No images appearUse PNG, JPG/JPEG, BMP, TIFF, or TIF files and verify folder access.
Crop/conversion failsRun magick -version in a new PowerShell window.
Launcher cannot find .NETInstall .NET 10 or update PHOTOTOOLS_DOTNET in the launcher.
Developer Mode errorEnable Settings → System → For developers → Developer Mode.
Old shortcut failsThe shortcut has an absolute path; use the BAT launcher or recreate it.
